# 層A（視覚的保持／エンコーダ瓶頸）

視覚エンコーダが**微細形状やパターン差**を埋め込みに保持できているかは、しばしば「視覚的詳細保持（visual detail retention）」「エンコーダ瓶頸（encoder bottleneck）」「CLIP-blindペア」などと呼ばれます。Tongらの「Eyes Wide Shut」では、CLIPが区別できない画像ペア（“CLIP-blind pairs”）を検出し、細部を捉えられないエンコーダの限界を指摘しています。この研究では９つの基本的パターン（向き・個数・色・構造など）でVLMに簡単な質問をさせるMMVPベンチマークを作成し、最新MLLMの視覚回答能力が乏しいことを示しました。類似の診断手法として、MMVP-VLM（CLIP用の簡易版）やCLIPとDINOv2の線形プローブ比較、埋め込み間距離分析などが考案されています。たとえばMMVP-VLMでは、CLIP系モデルに対し視覚パターン（回転・重なり・透視など）の多肢選択問題を課し、パラメータ増加でもほとんど精度が上がらないことが報告されています。これらは**エンコーダ表現の欠落**を直接検証するためのベンチです。

これらの手法は、CLIPのビジョンエンコーダ表現を修正し微細特徴を残存させることを狙います。一方で**限界と副作用**も指摘されています。エンコーダ表現のみを改変しても、欠落した情報を完全に追加できない場合があります。また、SFT（教師あり微調整）やRLによる事後学習では、視覚表現の改変が他の能力（ゼロショット精度や言語理解）に影響を及ぼすリスクがあります。実際、LargeVision-LMの微調では視覚的フォーカスが改善する一方で、言語依存症に逆戻りしないようRL戦略が必要とされています。これらを総合すると、**視覚エンコーダを書き換える強化**は微細認識を向上させるものの、完全復元や他能力維持には細心の設計が求められます。

**この研究への含意:** 層Aの研究から、我々のタスクに必要な**微細視覚保持**は標準CLIP表現では不十分であることが示唆されます。事後学習で視覚エンコーダを強化し、形状差を埋め込めるモデルにするアプローチは有効ですが、ゼロショット性能を保ちつつ過学習や情報欠落を防ぐ工夫が必要です。特に「視覚-意味接地」がされない限り意味的整合性は達成できないため、エンコーダ改善のみでは不十分である可能性があります。

# 層B（視覚–意味接地／Grounding）

視覚的特徴と正しい言語概念を結びつける能力は、「視覚–意味接地（visual-semantic grounding）」「視覚的根付け（sensory grounding）」「モダリティ整合（modality alignment）」「シンボル根付け」などと呼ばれます。狭義には物体や領域と語を対応づけること（例: 画像中のりんごを「りんご」と認識する）を指し、広義にはモデルの回答や説明が**必ず画像に基づく**こと（推測ではなく視覚情報に依存すること）を含意します。「HallusionBench（CVPR 2024）」などの研究では、VLMが根拠なく見えていないものを言い当ててしまう事例が顕在化しました。

**診断用ベンチマーク例:**  
- **NaturalBench:** 2枚の異なる画像に対し同じ質問を用意し、答えが必ず異なるように作られたVQAセットです。モデルが言葉だけで回答する「盲解答」を防止し、対話的な視覚理解を試験します。  
- **SPEC:** FudanらのSPECベンチは、画像のサイズ・位置・有無・個数など微細属性の一致を問うデータ合成型評価です。現行VLMは人間と比べほぼランダムであり、視覚根付けの弱点を示しています。  
- **POPE:** オブジェクト検出において「画像にこの物体はいるか」をYes/Noで答える検証で、Hallucination（誤認）率を算出します。  
- **HallusionBench:** VLMの出力に「視覚的根拠のない情報」が含まれるかを評価する総合ベンチです（ParkらCVPR2024）。  
- **その他:** 画像の穴埋め問や語彙対応テスト等、モデルの回答が視覚証拠に裏付けられているかを検査する各種ベンチがあります。前述のNaturalBenchのように、「画像を見なくても答えられる」設計を排し、人間並の推論依存度を要求するのが近年の潮流です。

# 層Reasoning（比較推論・視覚CoT）

視覚的な**比較推論**とは、複数候補を並べて**差分**を見極めたり、画像間で情報を統合した推論を行う能力です。これには「視覚的比較推論」「差異推論」「視覚的CoT」などの呼称があります。たとえば、2枚の図面を比べて違いを答える「spot-the-difference」や、複数の候補から最適解を吟味する問題が該当します。診断ベンチには、前述TIR-BenchのSpot-the-Difference（100例）やJigsaw・ローテーション・比率問題などがあります。また、**BLINK**ベンチマークでは「一瞬で認識可能な画像問題」を集め、現代MLLMの視覚CoT能力の低さを明らかにしています（評価サイト）。さらに、CV-Bench（NYU-VisionX）などの新規視覚VQAベンチも立ち上げられています。

# 層をまたぐ原因帰属

ある失敗事例が**層A（エンコーダ）、層B（接地）、層C（推論）**のどれに起因するかを切り分けるには、実験的手法がいくつか考えられます。たとえば、埋め込み表現に失敗要因となる差異が含まれていないなら層Aの問題と診断できます。逆に埋め込みには情報が含まれているがLLMの出力に現れない場合は層B（接地不足）の可能性があります。TongらはCLIPと自己教師表現の比較でCLIPに情報欠落があると分析し、MLLM出力のエラーをエンコーダ側の問題に帰属しました。また、Vision-SR1やViGoRはRL報酬の観点から可視化し、潜在表現やAttentionの変化を解析しています。SFTとR1型学習でエンコーダの表現がどのように変わるかを見ると、SFTでは一般に埋め込み空間に大きな変化は少なく、R1系ではAttentionが細分化されやすいという報告があります。これらから、「どこに投資すべきか」は状況依存ですが、近年は**視覚的詳細の保持が律速**であるとする示唆が多いです。例えばEyes Wide Shutでは、CLIPレベルでの能力不足に着目し、エンコーダ改善が重要と述べました。ただし、情報欠落がない場合には接地・推論面への学習が効果的であることも多く、最適化の優先順位はケースバイケースです。

# 論文のポジショニング

近年、**「識別ベンチ＋事後学習」**型研究が主要会議で成立するには、能力一般化の示唆や根本原因分析が求められます。成功例に挙げられる論文群は以下の特徴を持ちます。

- **能力プローブ化:** Eyes Wide ShutやNaturalBenchは、ビジョン系LVMの限界を具体的な能力単位で示しました。能力名やベンチ名を前面に出し、狙いが明確です。  
- **汎化的示唆:** SPECやVisual-RFTでは、特定タスクに限定せず「細粒視覚理解」「CoT推論」など一般能力として提案します。あえてドメイン語（例えば“特許”など）は論文中に出さず、「一般的な細粒化問題」として述べています。  
- **方法の普遍性:** Cambrian-1（MLLM）やPIVOT (V-STAR) では、手法がモデルやデータセットを横断して効果を示しています。Visual-RFT/PIVOTは「R1手法の拡張枠」として、他タスクへの転用可能性を強調します。  
- **接地先:** 上記では「接地した視覚認識は推論の前提である」という文脈を組み込み、語り口を調整しています。たとえばEyes Wide Shutは視覚自己教師機能の追加を提案し、「視覚的根底を固めることがマルチモーダル推論向上の鍵」と訴えました。  
- **文言選択:** タイトル/要旨では「細粒度認識」「視覚理解強化」等とし、ドメイン固有名詞を避けています。たとえば「Fine-R1」はドメインを指定せず、「多様なFG認識で優れる」と主張しています。  

このように、**一般能力の延長上に本研究を位置づける**ことが成功例に共通しています。特許図面というニッチな例を用いる場合でも、その狙い（細粒視覚差異の認識能力強化）が「汎用的ビジョン・言語能力向上」であることを強調する工夫が鍵です。

# まとめ：現在の主張と未充足のギャップ

- **A層（視覚的詳細）:** 現在、CLIP系モデルは細部の差異を埋め込みきれず、事後学習である程度改善できる。最新手法（DIVAやMoFなど）はCLIPの注意を補強し、細部認識を高める効果を示している。しかし、完全に情報を取り戻すには**依然ギャップ**が大きい。具体的には、微細形状の信頼性の高い埋め込み化や、汎用性維持のための最適なトレードオフ手法は未確立です。  
- **B層（視覚–意味接地）:** テキスト依存や幻覚を抑えるため、強化学習的手法が成果を出しつつある。現状ではRLHF-Vや対比学習によって根拠付き出力が増加し、部分的に改善しています。一方、「保持情報を持つが接地失敗」なケースを分析した研究はまだ乏しく、どの程度エンコーダに情報が存在するかを切り分けるメソッド（例えばペア評価やプローブ分析）の整備が不足しています。  
- **C層（推論・比較）:** 視覚CoT強化により顕著な性能向上が報告されている。特に、わずかな教師データでモデルの差分検出能力を飛躍させる枠組み（SpatialReasoner-R1やFine-R1）が開発されています。しかし、**知覚能力がボトルネック**の場合、いくら推論を磨いても成果は制約されます。現時点では、視覚強化と推論強化の**どちらが律速**になるか明確ではなく、両面の統合的アプローチが求められるギャップがあります。  

以上を踏まえ、本研究では特許図面のような特殊ドメインでも、層A～Cのどの要素を強化すべきか注意深く見極める必要があります。調査からは、**視覚的詳細の維持とその正しい接地**の両輪が不可欠であり、どちらか一方では十分な解答率が得られない点が見えてきました。また、事後学習ではゼロショット性能維持の観点も忘れてはならず、RL vs SFTのバランスや新旧能力の干渉に注意する必要があります。
