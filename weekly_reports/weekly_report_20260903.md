# 週次MTGレポート — 2026-09-03

## ベンチマークの必要性・有用性

非常に似た形状の物体を識別することは、VLM にとって必要な能力である。それを測るベンチマークとしては Fine-Grained Visual Classification(FGVC, 鳥の種類、車種、犬種など、非常に見た目が似ている下位カテゴリーを高精度に識別する) に代表されるものがあるが、FGVC は特有の専門知識を要求することを目的としており、多くのユースケースに対して当てはまるものではない。現実世界には、異なるカテゴリ間の物体同士でも形状が似ているものが存在し、これらを識別できることは、多くのユースケースに用いられる VLM にとって重要な基礎的能力である。しかし、それを測るベンチマークは今までになかった。

## 事後学習手法の先行研究調査（能力の3層分解）

このベンチマークに対して VLM の識別性能を上げる事後学習手法を、能力を3層（A: 視覚的保持 / B: 視覚-意味接地 / Reasoning: 比較推論）に分けて先行研究を調査した。同一の調査依頼を3系統の Deep Research にかけ、結論を突き合わせた。

| 層 | 事後学習で有効とされる手法 | 診断法 | 到達度・限界 |
|---|---|---|---|
| **A 視覚的保持** | 生成フィードバック／反転でエンコーダ表現を書き換え（DIVA ICLR25 / un²CLIP NeurIPS25 / GenHancer ICCV25 / FineCLIP NeurIPS24 / FG-CLIP ICML25）。MMVP-VLM で +3〜13pt、ゼロショットは維持 | MMVP-VLM、CLIP と DINOv2 の線形プローブ比較、拡散反転による再構成プローブ | 人間の95.7%に遠い。クロスモーダル整合のドリフト、拡散フィードバックの計算コスト |
| **B 視覚-意味接地** | 最小視覚差ハードネガ＋対照／選好最適化（S-VCO ACL25：幻覚 −22% / Finedefics ICLR25：LLaVA1.5 で +14% / RLHF-V CVPR24：物体幻覚 −75.8% / AHNPL IJCAI25 / CLoVe：patching で忘却回避） | NaturalBench、POPE、HallusionBench、SPEC、選択肢を与えずに特徴を記述させる方式 | 「A 成立・B 失敗」は実証済み（線形プローブで9割超分離できるのに VLM はチャンス級）。既存手法は自然画像・領域テキスト前提 |
| **Reasoning 比較推論** | 検証可能報酬の RLVR／GRPO（Visual-RFT ICCV25：1-shot 細粒度分類 +24.3%／同設定 SFT は −4.3% / Perception-R1：1,442サンプルで SOTA 級 / ViCrit NeurIPS25 / Visual Jigsaw / fDPO・SpatialReasoner-R1 / Reason-RFT） | BLINK、CV-Bench、spot-the-difference、多候補比較プロンプト | 推論単独では知覚が律速（Perception-R1：既存 RLVR は知覚を有意に改善せず p=0.22、失敗の72〜78%が知覚エラー）。ただし比較 CoT ＋知覚報酬なら注目領域が識別部位に絞られ判別が跳ねる |

### 調査からの主要な示唆

- **層 A の改善余地は構造的に限られる可能性がある。** 誤答を DINOv2 類似度で選んでいる＝ DINOv2 的な形状特徴をエンコーダに足しても、誤答との分離が進むとは限らない。層 A の改善は必要条件だが十分条件ではない。
- **主戦場は層 B。** DINOv2 で作った酷似ペアは、そのまま S-VCO／Finedefics 型の「最小視覚差ハードネガ」に転用できる。LoRA 後の +1.9pt を超えるための最有力ルート。
- **SFT ではなく DPO／RL。** PIVOT 系（"RL makes MLLMs see better than SFT"）が、DPO は視覚アテンションを鋭くし線形プローブで +1.8〜2.0pt、DPO のみデータスケールで表現が改善する、という一次証拠を出している。「知覚を検証可能報酬にした RL／DPO」が費用対効果最大、というのが3件共通の推奨。
- **原因帰属（attribution）の3ステップ診断が3件でほぼ一致した。** ①エンコーダの線形プローブ／コサイン類似度 → 層 A、②選択肢を与えず特徴を記述させる → 層 B、③記述は正しいのに選択で誤答する → Reasoning。加えて、画像を正確なテキスト記述に置換して性能が跳ねれば知覚が律速、という切り分け法。

## FB

- 事後学習で識別能力を上げたとき、**学習に直接使ったクラス以外にも汎化するか**に興味がある。同一クラス内で学習データに含まれない未知のインスタンス（例：鳥の「種」のうち学習に使っていない種）まで識別できるようになる、という汎化が起きたら面白い。
- より踏み込むと、**そもそも学習データに一切含まれない未知のクラスそのもの**に対しても識別能力が上がるか、という問いもある。実現すればインパクトは大きいが、実現するかどうかはかなり怪しいと思う。
- この汎化には難易度の異なる複数の段階がありそう。(a) 同一カテゴリ内で一部インスタンスを学習から除いた場合の汎化（例：鳥200種のうち150種で学習し、残り50種を識別できるか）と、(b) あるカテゴリを丸ごと学習データから除いた場合の汎化（例：犬のデータを一切含まずに学習し、犬の品種を識別できるか）とでは難易度がかなり違うはず。どこまでできてどこまでできないか、その境界がデータの有無・量でどう変わるかを議論できるとよい。
- 最終的には意匠データと既存の自然画像データなどを全部合わせて学習すると汎化性能が一番上がる可能性もあるので、データの組み合わせ方をいろいろなパターンで試してみるとよさそう。
- 意匠データで学習して得た識別能力が、意匠以外のタスク・データセットに転移するかどうかも今後（おそらく後半のフェーズで）試していきたい。
- CVPRの作法（実験のやりかた，ベンチマークのサンプル数何個あったら良いか，表がいいか図がいいかなど）があるので，抑えておきたい，松尾研の採択論文を見てもいいし，AIに聞いても良い．
